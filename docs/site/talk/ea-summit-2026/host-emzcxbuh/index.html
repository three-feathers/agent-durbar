Poll host sheet · EA Summit talk

Thank you for running the polls. Five polls are spread through the talk and a word cloud closes it. When a poll slide comes up, the slide shows the question with a "POLL N — LIVE IN TEAMS NOW" banner: launch that poll. The presenter reveals the answer on the next press, after people have voted.

How, in Teams: in the meeting, open Polls (Forms) → New poll → Multiple choice, paste the question, then one option per field. For the end, choose Word cloud (or an open text poll if word cloud is not offered). Tip: prepare all six as drafts before the talk in this order, then just press Launch on each cue.
