# Agent notes

Pitfalls agents on this repo learned the hard way. Rules live in [AGENTS.md](../AGENTS.md); the review checklist is [review-checklist.md](review-checklist.md); checked facts about Copilot, Claude Code, Codex and `git` are in [agent-apps.md](agent-apps.md). This file is guidance and never overrides AGENTS.md.

Each entry: **what** (bold), why, how to apply, evidence (`real:`, `read:`, `test:`, `sim:`, a PR or issue), at most three lines. Add one in the PR where you learned it; fix or delete one that turns out wrong; delete one a script or test now enforces. **Never** secrets, tokens, personal data or chat contents. Push: `npm run specs:numbers`; pictures over 300 KB fail `npm test`/CI `spec-numbers`.

## Shell, git and processes

- **`pkill -f` / `pgrep -f` match their own shell**. Select by field (`ps -eo pid,args | awk ...`) or keep the PIDs you started (2026-10-20).
- **Plain Node 22.18+ can `require()` an erasable `src/shared/*.ts`** (no `enum`, `namespace`, parameter properties): a no-build script can reuse `redact.ts`; wrap it, fail closed on a throw; `process.features.typescript` tells a test (spec 008 FR-122, `real:` Node 22.23).
- **`npm test -- --bail`** stops at the first failure (not under `CI`), not for final runs (spec 008 FR-115).
- **systemd user units do not sandbox on an Ubuntu 24.04 VPS** (`apparmor_restrict_unprivileged_userns=1`): `InaccessiblePaths`, `ProtectHome`, `PrivateUsers` drop silently. Probe a setting with `systemd-run --user --wait --pipe -p <x> cat <file>`; use a separate unix user for isolation (FR-058, `real:` systemd 255).
- **The Write tool turns a ` ` escape into the raw character**, so `tsc` fails; write them with a Python edit, check with `perl -ne 'print if /[^\x00-\x7f]/'` (2026-10-25, `real:`).
- **A lock "check, then act" needs a short `wx` guard and an owner token**: re-check under the guard; write or unlink only while the token is yours; move a stale guard aside and check identity (never `lstat` then `unlink`). Test with an injected fs swapping the lock between calls; it narrows the race, not closes it (spec 083 FR-008, `test-notesstore.ts`).
- **Capture `child_process` functions at call time, not at load**: a function grabbed at module load bypasses the simulator's seal and test spies; pass a wrapper that reads `child_process.execFile` when called (spec 081, `test:simguard`).
- **Sealing a Node built-in works only on the real module object**: patch `require('child_process')` (`import x = require(...)`, not `import * as`: its `__importStar` copy has getters only; patch `require('fs')` to fake an fs call, PR #489); TS's CommonJS output reads `child_process_1.execFile` at call time, so the seal reaches `src/` (spec 010 FR-030, `test-simguard` §5). `test:ipcchannels` bans `ipcMain` and `.ipc` outside `ipcguard.ts`.
- **git rerere can replay a stale resolution and silently drop a rule** (no markers; it twice dropped `.mode-menu` from `styles.css`). After "Resolved ... using previous resolution", rebuild each file with `git merge-file -p ours base theirs` and diff it, or `git rerere forget <file>` during the conflict (PRs #488, #511, `real:`).
- **Your branch against another open PR**: `diff <(git merge-tree --write-tree --name-only origin/main B | grep ^CONFLICT | sort) <(git merge-tree --write-tree --name-only HEAD B | grep ^CONFLICT | sort)`; empty means you add no conflict for them (spec 074, `real:`).
- **`node_modules/` in `.gitignore` misses a symlink** (2026-11-05: a worktree's link got committed): use `node_modules`; stage by name.
- **Union-merged `CHANGELOG.md`, `README.md` or `tasks.md` conflicts can duplicate rows**: count rows per id after resolving.
- **`scripts/changelog.js` acts on the repository it lives in**: running another checkout's copy edits *that* checkout. Pass `--root "$(git rev-parse --show-toplevel)"` and check `git status` after (#650, `real:`).
- **Release refs: full names and `versionsort.suffix`**: `origin/main` can resolve to a tag `refs/tags/origin/main`; require `refs/...` and `git show-ref --verify`; sort tags with `git -c versionsort.suffix=- tag --sort=-v:refname` (#648, `test:changelog`).
- **A workflow cannot usefully open the fold PR with `GITHUB_TOKEN`**: its pushes and PRs start no `pull_request`/`merge_group` runs and Actions-created PRs need a repo setting: open the fold PR by hand from the tag (spec 008 FR-120, `read:` GitHub docs).
- **macOS adds `__CF_USER_TEXT_ENCODING` to every child's env**: ignore it in env allow-list tests (`test-weekly-audit.ts`); only `main` CI shows it (FR-106) (#765, `real:`).
- **A copy of `process.env` is a plain object**: on Windows its PATH key is `Path`, so `copy.PATH` is `undefined`; look keys up case-insensitively (#722, `real:` Windows CI).
- **A GUI-launched macOS app has `PATH=/usr/bin:/bin:/usr/sbin:/sbin`**: an npm (nvm, fnm, Volta, Homebrew) starting `#!/usr/bin/env node` exits 127. Run npm children with `pathWithToolDir` from a `posixTrusted` folder, from the found path before `realpath`; map 127/ENOENT to a clear message (spec 081 FR-042, `test:updatecheck`; not seen on a real Mac).
- **winget.exe and Store apps are App Execution Aliases**: `fs.statSync` throws EACCES on them and `realpath` leads to an unrunnable folder. Use `statIsFile` and `isAppAlias` in `src/adapters/detect.ts` (spec 060 FR-010, `read:` node-which#157).

## Tests and timing

- **Timing checks: measure CPU time, not wall time.** Use `process.cpuUsage()` (`cpuMs` in `test-redact.ts`), two sizes 8x apart, minimum of interleaved runs, a loose wall-time backstop and a 20 ms floor (Windows ticks are 15.6 ms). In a worker use `process.threadCpuUsage()` (Node 22+, not 20.19). Prove it with a quadratic mutant (spec 041 T068, PR #527).
- **Time the app, not the machine, under load**: let the app `performance.mark`/`measure` its work and on Linux subtract the renderer's run-queue wait (field 2 of `/proc/<pid>/schedstat`); a calibration loop did not see the load (#454, `real:`).
- **A test whose promise never settles exits 0 silently** (also with an `unref`'d timer): race a hang-prone call with a short timer, assert the value, set `process.exitCode = 1` until the success line, and print a final OK line (PRs #473, #631, spec 081).
- **End-anchored regexes on untrusted text can be quadratic** (`/\s+$/`, lazy `(.+?)\s*$`: 100k spaces took 61 s). Use `trimEnd()` or a loop from the end; put the long run *not* at the end in the timing case (PR #463).
- **Fuzzing a masking change**: one secret in ~20 shapes inside ~10 wrappers (`sh -c`, `cmd /c`, PowerShell, nested), compared with `main`; include one long word (`';'.repeat(n)+'x y'`) and check linear growth 20k to 200k (PR #369).
- **Shell-wrapper fuzz args as the OS passes them**: `sh -c` gets decoded text; `cmd /c` and `powershell -Command` keep `^`, `` ` ``, `''` and join args. Only escape-aware rules (`maskEscapedPairs`) run before a decode; cut repeated units at the same phase for both sizes (#447, `test-redact.ts` §14d).
- **`\b` does not separate `_` from a letter**: `/\bghp_/` misses `_ghp_…_` and `my_ghp_…`. Start shapes with a lookbehind (`START` in `src/shared/redact.ts`), test `_x_`, `my_x` and Markdown wrappings, mutate back to `\b` (#541, `test-redact.ts` §3b, §9).
- **Percent and backslash escapes end in a hex digit or letter** (`%3Dghp_`, `\nghp_` in the JSON debug log), so the lookbehind refuses them: `START` has a fixed-width second branch for `(?:%|25)XX` and `\n`-style escapes; keep it fixed-width and start long-prefix shapes at their literal (`eyJ`) (#543, #549, `test-redact.ts` §8).
- **A mask-before-cut test needs a bare token**: `Authorization: token` masks the rest even when cut first, so the test passes on a wrong order. Put a bare token across the cut; swap the order as the mutant (#511, `shots-001-lobby.js`).
- **`#1621` in a renderer comment is a colour literal to `test:theme-tokens`** (`#` and 3, 4, 6 or 8 hex digits): write `issue 1621` in `src/renderer/` (spec 058 FR-231, `test:theme-tokens`).
- **A contrast fallback must not touch shared surfaces** (`--surface`, `--bg`): fix only the text side, test a dark theme with one failing pair. A list copied between `src/renderer` and `src/shared` needs an equality test (#500, `test:theme-tokens`).
- **A send gate's busy check reads main's `lastStatus`, not `agentState`**: `agents:send` sets Thinking first (spec 058 FR-209).
- **A lookup table keyed by event or adapter text needs `hasOwnProperty`** (`'__proto__'`, `toString`), and number helpers need `Number.isFinite` (`Infinity` printed `InfinityM`) (spec 015, #601; spec 007 T038).
- **A test server that never reads a socket never sees it close**: call `s.resume()` on each accepted socket before awaiting `close`; list processes before blaming the product (PR #847, macOS).
- **Install Electron once before parallel Electrons** (`ensureElectron()` from `scripts/ensure-electron.js`), or first runs race on `node_modules/electron/dist` (`ETXTBSY`, "Could not find sentinel") (spec 008 FR-114, `sim:`).
- **Electron checks are heavy**: at most two drivers at once, `nice -n 10` (limits: `run-tests.js`, `check-parallel.js`).

## CI, review and merge

- **GitHub logins differ by API**: GraphQL gives a bot without `[bot]` (`github-actions`, `__typename: "Bot"`), REST with it; `gh pr view --json author` says `app/dependabot`, and `gh pr list` and `gh issue list` show the Actions bot as `app/github-actions` (2026-11-02): the same account as `github-actions[bot]`. The latest editor is GraphQL `editor` only. `who` in `scripts/trusted-lib.sh` handles it (FR-060, `test-trusted-content.ts`).
- **Wait until every check has settled**: some workflows add checks later, so "none pending" right after a push can be a false green. Wait ~90 s quiet; require the CodeQL check itself (2026-10-20).
- **Bot line comments and alerts drift apart**: GitHub keeps a CodeQL line comment after the alert is fixed, and an empty alert list can hide a fresh comment. Gate on `code-scanning/alerts?ref=refs/pull/<N>/merge` and `/head`, compare a comment's `commit_id` with the head, read `alerts/<n>/instances` (PR #388).
- **Every push dismisses approvals and `main` moves fast**: batch docs-only edits into one push, ask for re-approval only once CI is green on the new head (PRs #369, #377).
- **CI speed**: the ruleset does not require up-to-date branches, so merge `main` only on a real conflict; GitHub ignores `merge=union` drivers. A required workflow must run on `merge_group`; a `concurrency` key on `pull_request.number` needs `|| github.ref` (spec 008 FR-098..FR-102).
- **Free plan: count runner tickets, not minutes**: jobs waited 10-66 min, ran 0.3-3.4. Shard only when run time beats queue time, prefer parallelism inside a runner, never a `needs:` gate before required checks; a required check must always report (step-level skips). Measure `started_at - created_at` per job (spec 008 FR-104..FR-110).
- **Labels are read from the event payload**: re-running an old run does not see a new label; push or save the description.
- **A branch-only workflow cannot be dispatched**: its file must be on `main` first, then `gh workflow run <file> --ref <branch>` (#483).
- **Stacked PRs: GitHub's native stacks** (`gh extension install github/gh-stack`, `gh stack link <bottom> ... <top>`): merging a lower PR retargets the rest; merge bottom-up, same repo only. A stacked PR gets no CodeQL until retargeted to `main` (2026-10-21).
- **A green `Build and test (macos-latest)` on a PR proves nothing**: it is the FR-106 stub (#722).

## Simulator and drivers

- **Side-panel checks need `density=full`** (2026-11-02, #542): few agents get grown desks, not the side panel (spec 001 FR-042); only a forced density never grows (`shots-001-live-activity.js`).
- **`until()` returns `false` on timeout**: wrap every wait a check depends on in `assert.ok(await until(...), msg)` (checklist). A renderer that repaints with `await load()` right after `Promise.resolve().then(call)` reads stale state: start the call synchronously first (spec 058).
- **`bridge` in a driver's `js()` is the real preload, not the simulator's**: under `DURBAR_SIM` main refuses every channel but those on `SIM_OPEN_CHANNELS` (`src/main/simguard.ts`, `test:simguard`), so drive the UI or call `window.__durbarSimUi.bridge()`. The frozen preload ignores plain assignment (spec 010 FR-022..FR-027, PR #505).
- **`app.js` is one IIFE**: `ROOMS`, `SCHED`, `bridge` are unreachable from `ctx.js`. Read `window.__durbarSimUi.agents()` and the DOM, derive expectations from the simulator's seed, or move logic into a pure `src/main` function and unit-test it (spec 044 T067, spec 003 T030).
- **When the simulator bypasses main, test main's logic itself**: put the handler in a pure function a unit test drives; prove a setting survives restart by driving main's IPC handler on a stand-in `electron` with a real store (`test-characters.ts`, `test-newfolderipc.ts`); a reload in the simulator forgets picks (#814, #693).
- **Rules the simulator copies go in a marked block with an equality test**: `sim.ts` cannot import, so `/* simrecord:begin */` and `/* mcpcall:begin */` blocks are cut out, transpiled and compared (`test-schedules-runs.ts`, `test-mcpcall.ts`); keep them free of closure variables (spec 044 T066, spec 058 FR-187).
- **The scheduler harness's `advance(ms)` is one tick**: step by the interval in a loop when counting runs; pass `mono: () => harness.now` (spec 044 T061).
- **The simulator's start-up replay runs while `app.js` loads**: guard handlers that read a later script's `window.exports` (spec 100, `sim:`).
- **A new renderer script needs a line in `scripts/copy-assets.js`** and its `<script>` tag, or the page silently runs without it (`window.DurbarX` undefined); check `ls dist/renderer` and let a driver assert something it draws (#605, spec 087 T030).
- **A screen no driver opens can break unseen** (#474).
- **A new event type needs `EVENT_TYPES` in `eventguard.ts` and the contract's `TYPES`** (spec 087).
- **An issue number in a renderer comment is a colour literal**: `test:theme-tokens` counts `#` + 3-8 hex digits in `app.js`, `screens.js`, `scenekits.js`, `index.html`, comments included. Write "PR 642" / "issue 619"; "N literals, ratchet allows N-1" after a merge is often this (PRs #498, #511, #535, #642).
- **Theme values: two copies, one corpus**: typed-token grammar lives in `theme.js` and `src/shared/themetokens.ts`; change both (`BAR_*` too), run `test:theme-tokens` (`THEME_LITERALS_WRITE=1`, `inventory.js --update` lower). An inline custom property beats `html[data-ui=...]` in `themes.css` (spec 070).
- **`\s` inside a page-code template literal is `s`**: write `\\s`, `\\n`, `\\d`, and print the tested text in the message. Match time-left text as a range (spec 068 T021).
- **`webContents.executeJavaScript` waits for a returned promise**: end a line that opens a dialog with `void ...;0`. `H.calm()` hides `#toasts` for the rest of the run: use `H.clearToasts()` when you check a toast (spec 080).
- **`H.shot(..., {blur: true})` moves the focus**: a later Escape goes to the page and closes the chat. Shoot without `blur` or after the keys; re-appending a focused node drops focus (`focus({preventScroll:true})`) (spec 005 T085).
- **Hover-only controls in pictures**: a `DISPLAY` without a pointer reports `hover:none` (run drivers with `UI_SUITE_XVFB=1`, `shots:docs` with `env -u DISPLAY`); the xvfb pointer rests mid-window, so `H.shot` with `prep: 'calm'` parks it at (1, 1) (`keepHover` to keep it). Look at each picture (PRs 631, 735).
- **A page check that changes the page puts it back**: `pageCheck` used to leave `body.ren-show` on and every picture showed rename pencils (PR 631).
- **Do not wait for a short animation and its end state in one poll**: set a `MutationObserver` flag before triggering, then wait for the end state; read reduced motion from `matchMedia`, not an env flag (#511).
- **Reduced motion takes other code paths**: the Windows runner reports it by itself. Reproduce with `--force-prefers-reduced-motion`; when an animation's end does work, the instant branch must too (spec 001 FR-051).
- **A hover or focus driver on a Mac needs the window active and one mouse move at a time**: back-to-back `sendInputEvent` moves merge (no `pointerout`/`pointerover`): wait for `:hover` after each; `:focus-visible` needs `document.hasFocus()`: call `win.show(); win.focus(); wc.focus()` until true. A user dark theme sets `--card-waiting` and `--card-error` too, or `theme.js` pulls `--ink` toward grey (spec 001 FR-187, `real:` Mac, 2026-10-29).
- **A covered window stops drawing** (`visibilityState` hidden): test runs set `backgroundThrottling: false` and `--disable-backgrounding-occluded-windows`. Reproduce Windows-only flakes with `UI_SUITE_JOBS=4 xvfb-run -a node scripts/ui-suite.js` (spec 008 FR-103).
- **Check a transient state in the same `js()` call as its cause**: a demo turn can end before a poll (Stop button); `until()` is for states that stay (PR #498).
- **Comparison drivers race the first frame**: wait for `window.__durbarSimUi.settleNow()`, throw on a wait timeout, load a fresh page per capture; `settleNow()` draws a queued frame, so never use it where the page must draw on its own (spec 008 FR-113).
- **A cached layout misses late header parts** (siren, cost, MCP chips): an intermittent `check:office` failure is often this race. Force it with `__durbarSimUi.quietHeads(['siren'])` then `quietHeads([])` + `paint()` (spec 001 FR-023).
- **Measure top-bar fit in CI's font**: DejaVu is 30-60px wider than Noto. Use the DejaVu-only fontconfig recipe in `check-office-overlap.js`, floors, `simkinds=mixed`, every theme and `data-platform="darwin"` (+58px); call `window.DurbarFit()` after forcing (FR-164, `real:`).
- **Office layout pitfalls**: hide post-fitted parts in `#probe`; measure the ~15 px scroll bar; search `styles.css` before naming a class (`.ph` collided); track `<details>` from the `<summary>` click; a lone `flex-shrink` below 1 absorbs only its share (spec 001 FR-036).
- **Spare height is a step after the layout** (`spreadOffice`, `data-spread`): check vertical use with the row gaps (`check-office-fill` `ROWS`); measure drawn rows with `offsetTop` (#619).
- **`#probe` is sized only by a layout search**: a `renderOffice` branch that skips `chooseLayout` must still size it; a driver that hides a part to measure lays the office out again (spec 092 phase 2).
- **Lobby tiles: count `.slot.on`, not `.slot`** (the "+N" is a slot); give `.pv-more` its own width. A walk needs a drawn entry, so make room before asserting one. The coffee corner, Boss and Bank are busy at load: wait for `.place.busy:not([data-place="coffee"]):not([data-place="boss"]):not([data-place="bank"])` (spec 001 FR-034, FR-039, spec 068).
- **Read a desk's state from `data-state`**, never the first `is-*` class; name other modifiers without `is-` (PR #554).
- **A desk scene redraws only when its `data-sig` changes**: the active theme (`THEME.themeIdForCache()`) and anything drawn must be in it; switch themes through Settings in a driver, not by clearing `#stage` (spec 040 FR-023).
- **Blurred desk scenes come from composited animations**: `opacity`/`transform` animations in a scene SVG put what is drawn over them on a possibly blurred `Overlap` layer. `fill-opacity` is no fix (restyles 60 times a second, about 4x the CPU): the Flat halo is a still glow now (2026-11-02, spec 001 FR-210, `check-001-halo`); inspect with `LayerTree.compositingReasons` (#554).
- **Desks stay in the page in list view**: scope lookups to `#list` or `#stage`; open an agent with `H.openSimAgent(pick, card)`, never sweep all desks in one `js()` loop; re-render on purpose to test a flaky focus (spec 052 FR-173).
- **"Chat open" has no office**: `body.panel-open` hides `#stage-host`; check closed, open, closed. A window is at least 640x480 (`minHeight`) (spec 001).
- **A driver loads the `dist` of the tree it lives in**: to compare builds, `require` the tested tree's helpers or pass `index:` to `H.load` (2026-10-25, `sim:`).
- **Floors on: a driver sees one floor**: run every driver that loads `simfloors` (`grep -l simfloors scripts/*.js`); walk floors with `H.eachFloor` / `H.goToFloor` or use `simfloors=ground`. PageDown on the body does not scroll `#floor`; the key handler does (spec 092 phase 1).
- **`announce()` keeps the last text within 60 ms**: in a driver wait for each announcement (`until` on a `MutationObserver` list of `#srAnnounce`, filter "Floor ") before the next change (spec 092 phase 2).
- **A marker keyed on "a turn just ended" fires on the simulator's start-up replay**: gate it with `SIM&&!window.__durbarSimReplayed`; an opened chat makes a Done agent Idle (`Ready in <folder>`) (#691).
- **A driver that counts "today" needs a pinned clock** (`simclock=<ms>`, spec 001 FR-084): seeded schedules first run 12 minutes after start, so a run near midnight sees none (PR 621, `real:` CI at 23:54).
- **The answer bar hides while its card is in view**: count unsettled `.note.perm` cards instead. Any button in a permission note makes it a pending card whose buttons are copied (bar, Needs you); decide what the copies do and test with the card scrolled away (#587, #618).
- **Real input for mouse, drag and double-click**: `el.click()` has `detail` 0 like a keyboard; use `wc.sendInputEvent` (`mouseDown`/`mouseMove` with `leftButtonDown`/`mouseUp`; `clickCount` 1 then 2), as `shots-074-navigator.js` (`mclick`), `check-composer-toolbar.js` (`drag`) and `check-edit-popups.js` (a text drag ending on a backdrop: a synthetic click never shows it) do (spec 005 FR-045, spec 052 FR-237).
- **Simulator drivers on macOS**: Shift+`/` arrives as `/`; shortcuts use Meta and show `⇧⌘…`, so branch on `process.platform === 'darwin'`; set `enableLargerThanScreen`; take layout snapshots after two identical measurements. A Windows capture after two quick loads may throw `UnknownVizError` once: settle and retry (spec 008, PR #497).
- **`askDialog`'s button row does not wrap**: give a dialog with more than three buttons `size:'l'` and check every `.dbtn button` lies inside `.dlg` at 1280x800; its `aria-modal` is on the inner `.dlg` (`#modeDlg [aria-modal="true"]`). An Electron `MenuItem` without accelerator reads `null` in a driver, `undefined` in a unit test (spec 093, spec 007 T031).
- **`.mm-h` headings are upper-cased by CSS** and a flex chip's `innerText` has newlines between items: match case-insensitively and on `innerText.replace(/\s+/g,' ')` (spec 087).
- **Settings overflow**: `scrollHeight` counts hidden nodes; scroll `#screen .scr-body` yourself and assert `document.scrollingElement.scrollTop === 0` and `elementFromPoint` per control (spec 058 FR-085).
- **UI ids that moved**: chat settings (`#modeChip`, `#modelChip`, `#agentChip`, `#ctxChip`, `#mcpBtn`) sit in `#cToolbar`; Compact exists only while `#ctxMenu` is open; narrow panels move controls to `#ctMorePop` (check `getClientRects()`). Defaults are in `#defaultsPop` (`#defaultsBtn`); `#addFolder`, `#addWs` are top-bar buttons. Previous sessions: `#prevBtn` toggles, state in `localStorage['durbar.prevOpen']` (survives `H.load`) (specs 005, 006, 052).
- **The simulator's reply is busy**: to test a queued switch, wait with `setImmediate` until the last `status` is `working`, then call `setModel` in that tick (spec 007 T038).
- **Driver-reported MCP servers survive a simulated Restart**; `window.__durbarSimMcpRefresh` counts `agents:mcpRefresh` calls (spec 058 FR-082, FR-187).
- **A dark-theme screenshot needs a user manifest** (`window.THEME.setTheme({id, extends:'clean-office', tokens})`, see `shots-043-editor.js`); no built-in theme has a dark surface (spec 043 T012d).
- **jsdom has no `localStorage` on a `file:` URL**: use `http://localhost/` in unit tests (spec 043).
- **Timing the renderer**: patch a copy of the built `dist/renderer/app.js` (never `src/`), run old and new builds alternately and compare medians. Layout cost is mostly style recalculation: skip `<svg>` children in `#probe` and register self-only custom properties with `@property` (spec 001 FR-033).
- **Windows runners take the window's focus at random** (2026-10-30 #891, 2026-11-01 #995): three drivers share one desktop, so `document.hasFocus()` goes false mid-driver (`:focus-visible` missing). A step needing focus retries only after a blur (`osRetry`), else fails naming what it saw. `H.focusPage()` / `H.focusWc()` ask for the real one; `{emulate: true}` (CDP focus emulation) hides blurs: `H.releaseFocus()` in a finally.

- **A driver whose window closes passes silently** (PR #915): `window-all-closed` exits 0 off a Mac; guard such a step with `win.once('closed', ...)` printing `DRIVER FAILED` and `app.exit(1)`. Windows CI reports `isVisible()` false: check `isDestroyed()`.
- **Reveal after `openPanel`'s re-stick** (`_rsBusy` clear; 2026-11-06, #1217); focus only from body, drawer or menu; the driver must fail mutants.

## Electron and platform

- **In Electron main, `app.exit()` and `process.exit()` skip Node's `exit` event** (`process.once('exit')` hooks do not run; `app.quit()` runs them). `crashmarker.ts:334` claims its hook covers `app.exit`: it does not. Clean up in `will-quit` (2026-11-04, `real:` xvfb probe, #1107).
- **`focus()` and `scrollIntoView()` scroll `overflow:hidden` ancestors too**: use `DurbarScroll.reveal`/`focusIn` from `src/renderer/innerscroll.js`; `test:innerscroll` refuses the raw calls. Pin `#floor:not(.scrolls)`, and in a driver watch `scroll` events, since the safety net hides regressions (#638, PR 641).
- **A DevTools command before a window's first navigation never answers**: load something first, or pass values in the query and act in the page's first script (`simclock.js`) (spec 001 FR-084).
- **`H.calm()` and `H.shot()` wait until no lobby figure walks**; pass `walking: true` only when the walk is the point of the picture.
- **Two captures of the same frozen state differ** by ~3,000 px inside animated desk scenes: compare with a tolerance or reduced motion.
- **Screenshots are palette PNGs**: `npm run shots:docs` compresses (`scripts/compress-shots.js`; `npm run shots:compress -- <file>` by hand); lossless tools gain nothing. Number the palette by first appearance; compare decoded pixels (PIL `ImageChops.difference`) and commit only changed pictures (spec 050 FR-012, #812).
- **Screenshot a static page with the repo's Electron under xvfb**: serve with `python3 -m http.server --bind 127.0.0.1`, a shown `BrowserWindow` and `capturePage()` (a hidden one hung); snap Chromium cannot read `/tmp`. `U+25BA`/`U+25C4` render as text arrows, `U+25B6` as emoji (spec 050 FR-014, `real:`).
- **A native `WebContentsView` is not in `capturePage`** and stays on top across a reload: capture the view separately and merge bitmaps (`shotWithView`); main removes views on `did-start-loading`; read `ctx.win.contentView.children` in a driver (spec 080 T015).
- **`safeStorage` is keyed by the app name**: never call `app.setName()` (`test-profiledir` fails); identity stays `agent-durbar` (PR #377).
- **Profile folders**: installed `<appData>/agent-durbar`, `npm start` and simulator `<appData>/agent-durbar-dev`; `DURBAR_USER_DATA=<folder>` wins (PR #377). A packaged build ignores it and `DURBAR_SIM` unless `DURBAR_DEV=1`, so it opens the real profile (2026-11-04).
- **A `src/shared` module with no imports loads in the page** as `../shared/<name>.js` after `exports-shim.js`; keep `exports` global (tsc reads `exports.NAME` at call time). `test-liveact` fails if `redact.ts` gains an import (spec 001 FR-031).
- **A crash marker holds ids only, one per process**: remove it in `will-quit` and `process.once('exit')` (driver runs end with `app.exit()`); tell boots apart by `os.uptime()`, not the wall clock; `fstat` before reading; never read or written under `DURBAR_SIM` (`DURBAR_SIM_CRASH=N`) (spec 006 FR-038, `test:crashmarker`).
- **Editing another app's config file: never re-serialise it**: `JSON.parse`+`stringify` changed indent, big numbers and escapes. Edit the member's byte range (`jsonEdit` in `src/main/mcpglobal.ts`), write secret-holding files owner-only with `flag: 'wx'`, re-check the hash before rename, pass secrets to a child as a 0600 file, never argv (#489, `test:mcpglobal`).
- **Reading a file a repo ships: call `readCapped` (`src/shared/cappedread.ts`), never copy it** (FR-031): `O_NOFOLLOW | O_NONBLOCK`, `fstat` regular file with one link, cap; after `realpath` refuse `.git`; test hangs in a child with a timeout (#535, #917).
- **A shortcut clash check needs more than the app's keys**: macOS Control letters edit text, IBus owns Ctrl+Shift+U/E, and handlers match `e.key` or `e.code` (Dvorak). Refuse a recorded shortcut whose position or typed letter is taken (`clashOf` in `navigator.js`); `test-navigator.ts` scans `app.js` (#552).
- **CSS subgrid rows count the row's padding inside the first and last tracks**: add it to those track sizes and measure the cell (#812, spec 001 FR-182).
- **Scene pictures**: an `<image href>` with a relative path works under `img-src 'self'`; detect a broken one with `new Image()` + `decode()` and key it in `data-sig` (`check-crew.js`). Pillow `save(..., 'WEBP', exif=b'')` writes clean chunks (`test:crew-assets`) (spec 077).
- **A new crew's `FACE` points do not move a couch seat's face**: the crop is anchored on the face point (62% across), so only the pixels decide whether the chat badge covers the face; on a `check-crew` seat failure, look at the picture. Read new points on a 50 px grid with a red 110x140 box beside a Cheeky one (#815). The Retro Pixel bed step flaked (3/5) until it measured once two reads 300 ms apart agree.
- **A destroyed `WebContentsView` has no `webContents`**: keep the `webContents` before `close()` to check `isDestroyed()` and the OS process (`process.kill(pid, 0)` gives `ESRCH`). `Page.getNavigationHistory` gives each entry a `transitionType` (`form_submit` for a form), so main knows a form page without reading it; `sendInputEvent` (`char`) fires a view's `input-event`. `sim:` spec 080 T013/T018.
- **The simulator's End session never reaches main**: a driver that checks a browser teardown uses the driver-context hooks `ctx.browserGone` / `ctx.browserStates` (`main.ts`), not the renderer.
- **No referrer from a custom scheme** (2026-10-31): a `durbar-sim:` `_blank` has `referrer.url === ''`; test referrer rules over loopback http (`check-browser-tabs.js`).
- **A child's `TMPDIR` needs room for Unix sockets** (macOS: 104 bytes): use `makeSocketSafePrivateDir` (spec 087 FR-024).
- **CSS anchor positioning** (2026-11-05, #1155, Chromium 125+): `anchor-name`s are document-global, so unique, and precede what they anchor; guard: `check-097-plate-pencil`.
