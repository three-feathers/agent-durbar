- **Compacting on the desk** (spec 015, issue #601): while an agent app summarises a long conversation, the agent's desk, list row, chat header and strip say **Compacting** (*Compacting the conversation…*), and the chat leaves a line where history was summarised. Claude Code (`status` and `compact_boundary`), Codex (`contextCompaction` item) and Copilot's `session.truncation` (older messages dropped, worded as such, never "compacted") now give the same normalized event Copilot's compaction already did. After a compaction whose new size the app does not report (Codex, and Claude when it sends no `post_tokens`) the context ring says it waits for the next message instead of the old figure, and the "nearly full" note does not fire on it. The gauge maths now treats `NaN`, `Infinity` (as the size in use or the window), strings and absurd sizes as unknown. Simulator and unit tests only (`test:compaction`, driver `shots-015-compact`); the Claude, Codex and truncation shapes are read from documentation and types, not seen on a real session.
