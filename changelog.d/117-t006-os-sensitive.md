- **Windows UI checks only where Windows matters** (CI, spec 117): a pull request runs the Windows UI shards only when it touches an OS-sensitive file (main process, preload, build, packaging, dependencies, CI files, fonts, shell scripts, an OS-using shared or adapter file, or any path not known to be OS-neutral); otherwise Windows UI runs after the merge, nightly and by hand (`gh workflow run ui-platforms.yml --ref <branch>`). A newer merge to `main` cancels the older `main` UI run, while nightly and by-hand runs always finish. Guarded by `test:ciossensitive` and `test:uievents`.
