- **Tool call arguments are masked in main too**: Durbar now masks a tool call's arguments before they reach the window or the debug log, as well as in the chat's tool chip, so the window never holds a value the mask hides (defence in depth). Harmless arguments read exactly as before, as long as each text is at most 12,288 characters (the masks' own input limit) and the whole set stays within a fixed work budget. A longer text is never cut and never shown in part: it arrives empty, as the tool chip already showed such an argument, so a very long helper task prompt is no longer shown in the helper card. A file's content next to its path is not sent to the window at all (nothing there shows it). Very large argument sets are replaced by the mask in bounded time (spec 005).
