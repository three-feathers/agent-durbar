- **Tool call arguments are masked in main too**: Durbar now masks a tool call's arguments before they reach the window or the debug log, as well as in the chat's tool chip, so the window never holds a value the mask hides (defence in depth). Harmless arguments read exactly as before up to 12,288 characters per text; a longer text is cut there (at its last space, or at the limit when it has none), as the tool chip already showed it, so a very long helper task prompt now ends at that point. Very large arguments are replaced by the mask in bounded time (spec 005).
