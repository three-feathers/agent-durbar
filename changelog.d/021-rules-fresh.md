- **A merge-gate run from a stale checkout refuses, and `npm run rules:fresh` names the rule files that changed on main** (spec 021 FR-424, FR-425): `rules:fresh` fetches `origin/main` by an explicit refspec and lists each changed rule file (`AGENTS.md`, `CLAUDE.md`, the Copilot instructions, `docs/rules/`, the constitution, the agent and skill files) as `file: <short sha>`, never a commit subject, then `rules: fresh` or `rules: stale, read: ...`. `scripts/pr-gate.sh` blocks with `stale-gate(...)` when one of its own files differs from `origin/main`'s, the fetch fails, or git fails in a checkout; `scripts/gh-trusted.sh` refuses on the same grounds (and compares itself too), except in a folder with no `.git` such as the pre-review bot's copy; `scripts/claim.sh` still claims but prints a note naming the stale files. The gate's input files are pinned to LF in `.gitattributes`, so the compare does not depend on `autocrlf`.
