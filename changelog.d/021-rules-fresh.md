- **A merge-gate run from a stale checkout refuses, and `npm run rules:fresh` names the rule files that changed on main** (spec 021 FR-424, FR-425): `rules:fresh` fetches `origin main` and lists each changed rule file (`AGENTS.md`, `docs/rules/`, the constitution, `CLAUDE.md`, the agent and skill files) with its commit subject, `rules: fresh` or `rules: stale, read: ...`. `scripts/pr-gate.sh` blocks with `stale-gate(...)` when one of its own files differs from `origin/main`'s, `scripts/gh-trusted.sh` refuses when the trust list or filter differs, and `scripts/claim.sh` still claims but prints a note naming the stale files.
