- **Opening a chat never scrolls the window** (spec 052 FR-176, issue #638): showing a waiting question (*Show question*, opening a chat at its request), answering or skipping it and focusing the message box no longer push the chat header off the top and leave a blank band at the bottom. Every focus and scroll into view in the chat now moves only the chat's own scroller (a shared helper, also used by Settings), and a safety net puts the page back if anything scrolls it anyway. Checked by `test:innerscroll` and the simulator driver `check:chat-no-scroll` at 1440x900, 1280x800 and 1280x520; not yet run on a real Mac.
