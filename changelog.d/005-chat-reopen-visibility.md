- **Long chats open faster, and keep following the end** (spec 005 FR-210..FR-215): when you leave a chat, its older messages are marked with their measured height, so reopening a chat of 4,000 simulated messages lays out only the ones near the view (the timing of each run is printed by the driver, never asserted; a long history opened for the first time is not faster, nor is a chat closed from its Browser tab). The marks are dropped when the width or a layout setting (density, theme, font) changed (FR-213), and for a message that changed while the chat was closed (FR-215). A chat scrolled up, even by a little, is no longer pulled back to the end by a streaming turn, and a late scroll event no longer stops the chat from following a turn (FR-214). Scrolling, copying across messages, find and keyboard focus are unchanged. Simulator only; not run on Windows or macOS.
