- **Notes: *Keep it out of commits* on macOS for folder names with accents** (spec 083): a folder name in some Unicode forms got an exclude line git did not match, so `git add -A` could stage `.durbar/notes.md` while the switch said *Added*. For a non-ASCII name the line on macOS now holds a wildcard over the accented part of its name on disk, so it matches any form; it also hides the `.durbar/` of other folders that fit the pattern, for a name with no ASCII every folder at that depth, from `git status`, `git add -A`, `git checkout`'s safety check and `git clean -X`. A name that cannot be read is refused. A folder whose switch is already on gets the new line when the switch is turned off and on again. Checked with a real `git add -A` on APFS, with git's `core.precomposeunicode` on and off.
