- **Notes: *Keep it out of commits* now works on macOS for folder names with accents** (spec 083): a folder path in decomposed Unicode form got an exclude line git did not match, so `git add -A` could stage `.durbar/notes.md`. The same happened for a folder mixing both forms, given with another case in an accented letter, or holding a compatibility letter beside a decomposed one. On macOS a line is now written for each form of the name as given and as it is on disk; a name no form can match, or one that cannot be read, is refused. A folder whose switch is already on gets the new lines when the switch is turned off and on again. Checked with a real `git add -A` on APFS, with git's `core.precomposeunicode` on and off.
