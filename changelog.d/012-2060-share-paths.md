- **Network share paths shown whole** (spec 012, issue #2060): a Windows share path (`\\server\share\folder\file`, also written with `//`) now shows its server, share and folders on your own screen, in error texts, helper cards, the activity line, toasts, strips and what the screen reader says, instead of `~`. Secrets inside a path (a password in an `smb://` link, a token-shaped folder, a token in a link) stay hidden, and the MCP diagnostics copy for an issue report keeps hiding a share path's server and share. Checked with labelled tests and mutants; not checked on Windows or macOS with a real share.
