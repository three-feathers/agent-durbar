- **A schedule has its own mode** (spec 044 FR-180..FR-184, T140..T143): each scheduled prompt runs in its own Read-only, Ask first or Allow all, for that one turn; the session then returns to its own mode, which is never changed or saved by the run. Allow all on a schedule is confirmed in words naming the schedule and the agent, from the window only, and asked again when the prompt, target or mode changes; a run that would go to another agent is not sent. Organization policy is checked at save and at each run. Schedules from before this version send nothing and say *Waiting for a mode*: one popup asks after the update (it never picks), and each row keeps *Choose a mode*. Autopilot on a schedule is not available yet: a stored one is kept, not sent. Checked with unit tests, a fake adapter and the simulator at both sizes; not on a real agent app.
