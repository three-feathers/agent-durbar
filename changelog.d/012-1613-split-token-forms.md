- **A token split by a line break, an accent mark, an HTML comment or tag, an invisible character or its `&#8203;` entity is now hidden** (spec 012, issue #1613): the shared secret mask read such a token as two harmless pieces and showed it on the desk, in tool labels, in the permission card's labels, in the activity log and in exports. It now reads the text once more with those pieces taken out, and hides what forms a token there, also in the plain desk line. A line break stays in the shown text. Some rare spellings still show; spec 012 FR-182 lists them.
