- **Export, delete all and removed folders' notes** (spec 083 T034b, FR-048, issue 699): the Notes screen has **Export…** (main shows the system save dialog and writes every note, done ones included, in the `notes.md` format, masked with the values known now, no session ids, mode 0600, atomically, refusing links, hard links, folders and devices) and **Delete all…** (asks with the count, Cancel focused, then a system dialog; tombstones kept). **Remove folder** asks in Durbar's own dialog, with **Also delete its notes (N)** (unticked, only when the folder has notes; ticked, a system dialog asks and only that folder's notes file is deleted; `.durbar/notes.md` is never touched). The simulator writes nothing. Checked with `test:notesexport` (real temp folders, a fake save dialog, the IPC handlers on a stand-in Electron) and the driver `check-notes-export` at 1440x900 and 1280x800; not checked by a person on Windows or macOS.
