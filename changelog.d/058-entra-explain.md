- **A refused sign-in by your organization is explained under the failed MCP tool call** (spec 058 FR-193, FR-194, issue #841): when a tool fails with an Entra Conditional Access code (for example `AADSTS530003`, a managed-device check), the chat shows one fixed line saying this usually means your organization's sign-in rules refused it, and that signing in again from Safari or Edge may help (Chrome needs the Microsoft Single Sign On extension), with a **Sign in again…** button that opens the MCP servers dialog. The server's own error text is never repeated in that line. Not yet run against a real tenant.
