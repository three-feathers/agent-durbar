- **Test builds from branches** (spec 008 FR-121..FR-124, owner decision, #658): a tag such as `v0.1.0-alpha.15-test.1` may be on any branch and builds a draft pre-release, never *latest*, titled "(test build)". Its notes list the branch's commits that are not on `main` (subject lines, masked and shown as code, at most 100) and the PRs they name; nothing goes into `CHANGELOG.md` or the README, and a test build never counts as the previous release. Regular tags must still be on `main`. Checked by unit tests on throwaway git repositories and a local dry run; the workflow has not run on GitHub with a test tag yet.
