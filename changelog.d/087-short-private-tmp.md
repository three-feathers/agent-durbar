- **Playwright MCP starts again in Copilot sessions on macOS** (spec 087 FR-024, issue #1173): since v0.1.9 Copilot's runtime gets a private temp folder, and on macOS its path was so long that Playwright MCP could not create its socket ("Socket directory path is too long"). When the system temp folder is too long for a socket path, the private folder is now made under `/tmp` (`/private/tmp` on macOS), still private (0700) and removed like before. Windows is unchanged. Checked with `test:copilot-tmpdir` on Linux; not run on a real Mac.
