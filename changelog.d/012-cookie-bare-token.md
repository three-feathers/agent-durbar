- **A `Cookie:` or `Set-Cookie:` header with one opaque token is now hidden** (spec 012 FR-168, issue #1159): `redact()` hid `Cookie: name=value` pairs but showed `Cookie: <long token>` whole. A single token of 8 or more characters is hidden, also after pairs, with `Set-Cookie` attributes kept; prose like `cookie: my session bug` stays. Checked on Linux by `npm run test:runtime-redact`; not run on Windows or macOS.
