- **An escaped token is hidden everywhere the shared masks run** (spec 012 FR-181, issue #1541): a token written with a backslash inside (`ghp\_…`, `g\hp_…`, `sk\-proj\-…`) was shown, whole or in part, in the "Approve for this session" label, the activity log and its export, the brain view's step targets, the MCP config view and copy preview, and the read tools' answers to the agent. These now hide it and keep the rest of the text as written. Text glued after a hidden environment value (`[redacted:NAME]_<rest>`) is now hidden like text glued after any other mask, also when that text is written with a backslash. The approval card hides a token cut by an escaped line break (`\n`) the same way. The reply line on a desk and the live readout hide the rest glued after an escaped token (`ghp\_…@…`) as the other surfaces do. A tool name longer than 256 characters is shown as "tool". Known, not fixed here: the desk's mask slows down on text with very many hidden-value markers (issue #1593).
