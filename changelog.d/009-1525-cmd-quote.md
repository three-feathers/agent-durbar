- **Windows: a `.cmd` program in a folder with spaces now starts** (spec 009 FR-029, issue #1525): VS Code's `code.cmd`, npm's `npm.cmd` and other `.cmd` programs went through `cmd.exe /d /s /c` without the outer pair of quotes that `/s` removes, so a path such as `C:\Program Files\nodejs\npm.cmd` broke at the first space. One shared helper now builds that line for all three routes and still refuses characters cmd.exe could interpret. Not run on Windows by the author; Windows CI runs the real case.
