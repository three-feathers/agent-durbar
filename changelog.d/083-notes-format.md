- **Notes file format** (spec 083 T040, issue 699): the writer and reader for `.durbar/notes.md` that the project-file mirror and *Export…* will use. No visible change yet. Notes are kept in creation order, so a new note only adds lines at the end. A file with git conflict markers outside code blocks is refused. A note added by hand with a bare marker line or a `## ` heading is read as a new note. Text outside notes is reported. Checked by `npm run test:notesmd`: 1,000 seeded documents, hostile input and every size cap.
