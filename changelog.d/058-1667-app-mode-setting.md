- **Copilot sign-in app for Microsoft Entra MCP servers** (spec 058 FR-233..FR-238, FR-240, issue #1667, experimental): with the Copilot SDK 1.0.32 runtime, Copilot's built-in Microsoft Entra MCP sign-in again uses Visual Studio Code's public app ID by default, as it did before; the stored setting can also be Off (no app, today's failure and the CLI steps) or your organization's own app ID.
