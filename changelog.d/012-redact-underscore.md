- **Security: a token after an underscore is masked** (spec 012 FR-080 delta, T127, issue #541; review of #532): `redact` no longer starts its token shapes at a word boundary, so a token in Markdown emphasis (`_ghp_…_`, `__sk-…__`) or glued to a `snake_case` word (`my_github_pat_…`) is masked wherever `redact` runs (debug log, live activity, desks, chat displays). The folder-setup window (spec 061) now uses the same shapes instead of its own copy, so it hides those tokens too. A JWT is masked in the same places (`my_eyJ…`, `MY__eyJ…`, `____eyJ…`; T128). Unit tests only.
