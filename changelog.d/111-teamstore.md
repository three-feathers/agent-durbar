- **Team templates have their store** (spec 111 T006, issue #1306): main keeps the templates in one file (`team-templates.json`, format `agent-durbar-team-templates`, at most 50), written by temp file, flush and rename (mode 0600 on POSIX), and a broken, newer or foreign-format file is moved aside once as `team-templates.bad-<time>.json` with one notice, never read whole when it is huge. Leftover temp files of dead processes are removed. Nothing shows in the app yet. Tested with an in-memory file system (15 mutants killed) and with the real one in a temporary folder; not run on Windows or macOS (the 0600 mode is POSIX only).
