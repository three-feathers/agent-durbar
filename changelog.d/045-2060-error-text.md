- **Errors say what went wrong** (spec 045): when an action fails, the message now shows the real reason (for example "EACCES: permission denied" with the file's path) instead of "something unexpected went wrong". The text is masked for secrets of known shapes, but masking of error text is best effort: secrets in some shapes can still show. The old sentence stays only when an error has no words. Checked by unit tests over every secret family the mask knows.
