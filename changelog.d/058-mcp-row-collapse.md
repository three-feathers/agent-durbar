- **MCP servers dialog uses the room, rows stay readable** (spec 058): the chat's MCP servers dialog is wider when the window has room (760 px instead of 560 px), so a server's name, state and buttons sit on one row, while its running text keeps a readable line length. A signed-in server whose state reads "Running · Renewed" with a date and time no longer squeezes its name to a few letters a line in a narrow window: the name and the state keep a readable column, the Renewed time stays on one line, and the buttons wrap below the text when they do not fit beside it. Checked in the simulator at 1440x900, 1280x800 and 900x700 (also zoomed), light and dark.
