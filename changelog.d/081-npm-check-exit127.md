- **Copilot CLI "Could not check: exit 127" on a Mac** (spec 081 FR-042): an app started from the Dock has no `node` on its PATH, so npm (found in nvm, Volta or Homebrew) could not start. The npm check, the npm update and sign-in runs now put the program's own folder first on that command's PATH (only when the folder is not writable by everyone), a missing npm or node says "npm or node was not found" with what to do instead of a number, the card's buttons are named *Check again* and *Check for update*, and "Found at" shows the full path of a system install. Unit-tested with fakes; not verified on a real Mac.
