- **Session browser: the Browser tab** (spec 080 T014, T015, T016, T018, issue #556): a chat now has Chat and Browser tabs. The first time you open a Browser tab, Durbar asks once (*Not now* / *Open the browser*) and remembers the answer. The tab has an address field (web addresses only; `file:`, `javascript:` and addresses with a user name are refused with a reason), Back, Forward, Reload and Stop, a Sound on/off toggle (sound starts off) and *Open in system browser*; each session's page lives in its own throwaway profile and is shown only on its own Browser tab. Menus, dialogs, toasts and the slash list that open over the page win: the page shows as a still picture behind them. A page's `beforeunload` shows Durbar's *Leave this page?* box (Stay focused); a page dialog in a session whose chat is not showing raises a toast naming the session, brings that chat forward once and marks it *Dialog open*. Checked on the simulator (its own test pages under `durbar-sim:`) on Linux; not yet on a real desktop, Windows or macOS. Chat links and the settings line for them come with T017.
