- **A token written with a shell's escapes is hidden on the approval card and the desk** (spec 012 FR-184, issue #1543): a command that spells a token with ANSI-C quoting (`$'…\x5f…'`), a JSON `\u` escape, a line continuation inside it (a backslash or cmd's caret before a line break), the PowerShell backtick or its `` `u{…} `` code, or the cmd caret, writes a header with an escaped colon and blank (or spells them as `\x3a\x20`), or writes a known secret value with a backslash inside, now shows `[redacted]` in its place, on the permission card, the desk, the activity row and the other masked views. Some surrounding text can be hidden with it (the header's name, a word glued to the token). Checked with tests; a comparison against the previous masks on tens of thousands of random texts was run by hand and is not part of the test suite. Where the card could not check such a command before, it still shows its neutral words instead of the command.
