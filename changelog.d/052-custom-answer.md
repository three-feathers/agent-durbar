- **A custom answer to a long question is an answer, not a skip** (spec 052 FR-178, issue #689): an answer to a question of more than 300 characters was dropped before it reached the agent, so the card showed "skipped" and the agent was told you skipped. An answer that cannot be read is now refused with a message and the card stays open. Unit test and simulator check; not run on a real session.
- **A skipped question says why** (spec 052 FR-178, issue #689): the card's tooltip and the debug log name the path that ended it (you pressed Skip, the turn was stopped, the agent app ended it), by code only, never the question or an answer. Added to find out why some answers were recorded as skipped; that cause is not found yet.
