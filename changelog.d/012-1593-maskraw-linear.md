- **The office's text masks keep their speed on very long agent texts** (spec 012 FR-183, issue #1593): a long reply with one Markdown mark and thousands of different secrets could hold the window for seconds while the desk line was masked, and a long command description in the "/" list could do the same in the app. Both passes now have a work limit; over it the desk shows its neutral word and the description one mask. A tool call or a past session's tool step with a name over 256 characters (or an MCP server or tool name that long) is left out, as other malformed events are. Checked with growth tests and a comparison against the previous masks on thousands of random texts: the same output below the limit.
