- **Full paths in the activity log and Agent apps** (spec 052, spec 081): Tools > Activity shows each folder's full path as written (a long one is cut in the middle; the whole path is in the tooltip and the accessible name), the CSV and JSON exports get a `path` column, and an agent app's "Found at" line shows the executable's full path instead of `~` or only a file name. Secrets inside a path are still hidden; diagnostics and issue reports keep their masking. Checked in the simulator and by unit tests; Windows and macOS paths are unit-tested only.
