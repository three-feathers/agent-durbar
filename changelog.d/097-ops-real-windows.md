- **Status counts in the top bar keep their width** (spec 097, Changes 2026-11-04): on a system font whose digits differ in width (seen on Windows), a count change made its pill a fraction of a pixel wider or narrower, which shifted the top bar and made it measure itself again. Each count now has a fixed width per digit. The simulator driver `check-office-ops-real` also sets motion on itself, so a Windows runner's "reduce motion" setting no longer makes its moving-people row find nothing, and it fails when any top-bar part changes size on a status update.
