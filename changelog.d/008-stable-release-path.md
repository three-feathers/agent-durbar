- **Release tooling handles a stable tag** (spec 008 FR-129): a tag such as `v1.2.3` makes a draft that is not a pre-release and, published with `gh release edit v1.2.3 --draft=false --latest` (printed in the job summary), is the latest release; alpha, beta, rc and test tags stay draft pre-releases, never latest. The decision is one tested function (`releaseKind`) that `release.yml` reads. A stable release's notes say "unsigned build" instead of "alpha", and `changelog:build` accepts a stable heading. Checked by `npm run test:changelog` with planted mutants; the workflow itself first runs on the next real tag.
