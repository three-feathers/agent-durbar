- **Your company's agent-app policy, before a session fails** (spec 076 section O, issue #602): Durbar reads the agent apps' own organization policies, read-only. That means Claude Code's `managed-settings.json` and its drop-ins, Copilot's policy through the Copilot runtime (with its `managed-settings.json` as a fallback), and Codex's `requirements.toml`. It greys out the permission modes, models, MCP servers and MCP tools they block, with "Blocked by your organization's <app> policy", and main refuses them at start and on a switch. Each key is read the way the vendor documents it; what Durbar cannot read that way is shown as advice and stays selectable. Policy files are read in linear time within size caps (over a cap the area is advice, never read as permissive), and a file whose text did not change is not parsed again. Fixture tests with a hostile-input matrix, a fake Copilot runtime and a simulator driver; not checked on a real managed machine.
