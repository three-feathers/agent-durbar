- **Copilot MCP sign-ins renew themselves after an expiry** (spec 058, issue #1201): when a call to a remote MCP server fails with a sign-in error, or Copilot reports the server needs a sign-in after it was connected, Agent Durbar reconnects that server once after the turn, in the background. No chat line, no delay when you send; the server's row in the chat's MCP list says *Renewed 12:40*. The call that failed still failed (the next one works), your message is never sent again, and there is no timer. Probed on a local test server only; not checked on a real Entra server, macOS or Windows.
