- **Copilot MCP sign-ins renew themselves at once after an expiry** (spec 058, issue #1201): when a call to a remote MCP server fails with a sign-in error, or Copilot reports the server needs a sign-in after it was connected, Agent Durbar reconnects that server immediately in the background (it waits only for another call to the same server in that chat), with *Renewed 12:40* on the server's row. If it worked, the agent gets one short automatic message to retry the step that failed, naming the server; that is one extra message and uses AI credits, and it is never sent at a spending limit, after Stop, or with *Refresh MCP sign-ins automatically* off. Your own message is never resent, and there is no timer. Probed on a local test server only; not checked on a real Entra server, a real model, macOS or Windows.
