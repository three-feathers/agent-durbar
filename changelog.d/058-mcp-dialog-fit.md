- **MCP dialog: long lists scroll, and a word never contradicts its switch** (spec 058 FR-077, FR-078, issue #544). With many servers the rows now scroll inside the dialog and *Settings*, *Folder extras…* and *Done* stay in view below them, and the *Restart session* row and its note scroll with the list instead of sitting on the buttons (before, the last rows and their switches drew over the buttons). A server the agent app turned off itself reads "Off in <app name>" (or "Turned off by the agent app"), its switch shows off, and a hint says to turn it on in the app's own MCP settings; A server Agent Durbar itself started as off (Settings, then switched on mid-session) reads "Off until the session restarts" with a pointer to *Restart session with these servers*. "Off for this session" is only for a server you switched off here, and "Off in Settings" / "Off in folder extras" for the others. Simulator and unit tests only (`test:mcpwords`, `shots-058-mcp-words` with 14+ servers at 1440x900, 1280x800 and 1280x600); not seen on a real agent app. The footer is now its own opaque layer above the scrolling list, so toggling a switch (also the last row's) can no longer put a row or switch over *Done* or the footer buttons (second report on #544; simulator checked at 1440x900, 1280x800 and 1280x600 with the toggle).
