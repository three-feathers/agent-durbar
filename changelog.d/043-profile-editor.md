- **View and edit profile files** (spec 043 FR-010..FR-017, owner request): *Settings > Profiles (custom agents)* and an **Edit** button in the Profile menu open a profile's Markdown file in a large editor with **Edit | Split | Preview**, a front matter check, a throttled preview through the chat's sanitised Markdown renderer, **Save** (Ctrl+S / ⌘S), an *Unsaved* mark, a question before closing with unsaved changes or overwriting a file changed elsewhere, and **New profile…** (Copilot or Claude Code, in a folder or your user folder). Owner decisions: the editor calls them **Agent Success Profiles**, and a new one starts from the default *Agent Success Profile* template (Title, People responsibility, Reporting to, Behaviors, Key Success Criteria, Skills, Tools and accountability, Key responsibilities) or a *Standard agent*; both start with read-only tools. Main owns every path: the window sends only ids from main's list (for files and, in New profile, for folders), links out of an agent folder are refused, writes are atomic and keep line endings. Applies to sessions started after saving. Unit tests and a simulator driver (`shots-043-editor`) at 1440x900 and 1280x800, light and dark; not tried on real agent files on Windows or macOS.
