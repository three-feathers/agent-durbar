- **Copy on a tool chip copies the real command** (spec 005): the chip still shows the command masked, but its Copy button now copies the command as the agent ran it, line breaks included, so a pasted command runs. When something in it was masked, Durbar asks first ("This copy may contain a secret") and copies only after Copy anyway. Durbar's main process holds the real text and writes it to the clipboard; the window never receives it. Checked with unit tests and the simulator; not yet on macOS or Windows, nor with a real agent session.
