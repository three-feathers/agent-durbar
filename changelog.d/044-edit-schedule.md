- **Edit a schedule** (spec 044 FR-022..FR-026, issue #522; owner's report): every scheduled prompt has **Edit…** in the folder's dialog and in Settings > Schedules. It fills the form (prompt, when, Send to, Limit); Save changes the row in place and keeps its last run, pause state and spend; an edit never drops a limit by accident. A done one-time schedule runs again when saved with a future time. The Settings button reads **Schedules for this folder…**, the cut prompt opens in full, and a long prompt no longer pushes Pause and Delete out of the dialog. Unit tests and simulator check `check:sched-edit` (1440x900, 1280x800); not seen on a Mac.
