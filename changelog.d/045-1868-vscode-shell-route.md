- **Open in VS Code on Windows never runs an unnamed command prompt** (spec 045 FR-065): when Windows' own folder settings name no full path to the command prompt, the fallback through VS Code's command shim is refused instead of letting Windows search for one, possibly in the current folder. A security review of that route found no way for folder or file names to reach the command prompt; unit-tested with hostile names on Linux, not run on Windows.
