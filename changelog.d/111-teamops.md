- **Team templates: the create preview, behind the scenes** (spec 111 T010, FR-030..FR-033, FR-039): main can now work out, for a template and a room, one row per member with the app's state in words, whether the model is offered and not blocked by your organization, the effort (an effort the model does not offer falls to its default; an effort from an imported template above the model's default is not used unless you pick it), the cost tier in words and the limit in the app's own unit (AI credits, an estimate in USD, or none), and keeps the preview for 10 minutes with a token. Changing a row's app drops its limit and never converts it. Nothing is started, no custom agent is listed, and a preview never raises permissions or touches Autopilot. The window that shows it comes with the Create team dialog (T014), so you cannot see this yet.
