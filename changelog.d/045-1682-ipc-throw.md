- **One answer for an unexpected error behind any window request** (spec 045 FR-066, issue #1682): when something unexpected fails in the app's main process while it answers the window, the window now shows one fixed message ("Agent Durbar could not do that: something unexpected went wrong. The details stay in its own log.") instead of the raw error text, and the real error goes to the app's own log, masked. The messages Durbar and the agent apps write for you (a refused start, a session that is not running, an MCP sign-in that cannot start) are shown as before. Unit tested; not run on macOS or Windows.
