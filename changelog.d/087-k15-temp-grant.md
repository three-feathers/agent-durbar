- **Copilot gets a private temp folder** (spec 087 FR-023, issue #755): Copilot's sandbox always keeps a temp folder writable. Durbar now starts the Copilot runtime with a private one (a new `durbar-cprt-` folder, mode 0700, removed when the runtime stops or the app quits) instead of the shared temp folder. The chip tooltip and the approval card now say that approved commands can write in that folder too. A real check on Linux found the extra writable place (2026-11-04); Durbar's own start of it has not been run for real, and macOS was not run.
