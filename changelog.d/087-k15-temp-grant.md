- **Copilot gets a private temp folder** (spec 087 FR-023, issue #755): Copilot's sandbox always keeps a temp folder writable. Durbar now starts the Copilot runtime with a private one (a new `durbar-cprt-` folder, mode 0700, removed when that runtime stops or the app quits) instead of the shared temp folder, with `TMPDIR` (and `TEMP`/`TMP` on Windows) pointing at it. The chip tooltip and the approval card say that approved commands can write there too. Checked for real on Linux and macOS (2026-11-04): a write in the private folder was allowed, and `/tmp`, the shared temp folder and the home folder were refused. Not run on Windows; Copilot sessions of the same run share the folder.
