- **A very large file written by an agent no longer stalls Durbar** (spec 012 FR-166, issue #1052): while a big `Write` streams in, the chat masks only the part it can show, instead of the whole file at every update. An 800,000-space write took about 9 s of CPU on Linux; on an Apple M4 it went from 2.2 s to 0.4 s. Checked with `test:edits`.
