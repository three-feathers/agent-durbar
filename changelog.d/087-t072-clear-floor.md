- **Allow all now turns Copilot's OS sandbox off in the running session** (spec 087 FR-022c, T066, T072, issue #806): switching a Copilot session from Read-only or Ask first to Allow all lowers its sandbox in place, and the Allow all confirmation says "Copilot’s OS sandbox is also turned off for this session."; switching back re-sends it. A real probe on Linux (Copilot CLI 1.0.98, 3 prompts) showed the sandbox clears in place and comes back; Durbar's own switch is tested on the simulator and with fakes, and macOS and Windows are not verified. If Copilot refuses or does not answer, a short message says so, the sandbox is treated as still on and *Restart without the sandbox* stays offered; an answer that comes later is followed, and a switch back to a narrower mode sends nothing until it comes. The T066 probe's cleanup now also removes the empty `.git/hooks` and `.git/config` placeholders the sandbox leaves in its session folder.
