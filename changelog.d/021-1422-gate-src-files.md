- **The merge gate reads CodeQL and the changed files more strictly** (spec 021 FR-090, FR-091, issues #1422 and the CodeQL check of #1479): `scripts/pr-gate.sh` now takes the CodeQL result only from exactly one CodeQL run by the `github-advanced-security` app that is tied to the run id, and reads the head sha again before it gives a verdict, so a push in between is caught. The check "this PR changes `src/`" reads the paginated files API, including the old path of a renamed file, and blocks the merge when that list cannot be read or its count differs from what GitHub reports. This is a tool for the team, not a change to the app. Checked by the gate's script tests only; not run against live GitHub, and not run on macOS or Windows.
