- **MCP errors hide the Copilot CLI list's keys too** (spec 069 FR-070, issue 1639): a server from `~/.copilot/mcp-config.json` that echoed one of its header or env values in an error showed it under *Details* and in *Copy diagnostics* when the value had no known token shape. Those values now join the list of values that mask a Copilot session's MCP errors, tool cards, edits and history, like the folder extras and Claude Code's list already did; plain setting values such as `true`, `production` or `1234` are left out so they are not hidden everywhere, and a value stays masked for the rest of the run after the file changes. They stay in main and are never shown or logged.
