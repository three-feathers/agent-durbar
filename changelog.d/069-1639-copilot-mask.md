- **MCP errors hide the Copilot CLI list's keys too** (spec 069 FR-070, issue #1639): a server from `~/.copilot/mcp-config.json` that echoed one of its header or env values in an error showed it under *Details* and in *Copy diagnostics* when the value had no known token shape. Those values now join the list of values that mask a Copilot session's MCP errors, tool cards, edits and history, like the folder extras and Claude Code's list already did; a value under a secret-looking name (`SMTP_PASSWORD`, `X-Api-Key`, `PIN_CODE`, `SLACK_WEBHOOK`, `SENTRY_DSN`) is always masked, and so is a URL whose path or host carries an id, while under other names plain settings such as `true`, `production`, `1234`, `https://api.github.com`, `/usr/local/bin` or `us-east-1` are left out so they are not hidden everywhere; a value stays masked for the rest of the run after the file changes, and notes and conversation search use these values also while the key vault is locked. They stay in main and are never shown or logged.
