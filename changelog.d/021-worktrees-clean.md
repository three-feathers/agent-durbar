- **Finished worktrees can be cleaned** (spec 021): `npm run worktrees:clean` lists the git worktrees of finished PRs and how much disk they use; `npm run worktrees:clean -- --apply` (the `--` is needed) removes only clean ones whose PR in this repository is merged or closed with the same head commit, nothing unpushed and no ignored file that a build cannot recreate; nested worktrees, merges in progress, locked or detached ones are kept. Dry run by default; checked with a temp-repo test and 32 mutants, not on macOS or Windows.
