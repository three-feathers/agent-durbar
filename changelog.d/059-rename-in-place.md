- **Rename in place** (spec 059, issues #636 and #595): click the chat title, or use the pencil next to a name on a desk card, a list row, a Previous sessions row or a folder (room header and Folders panel), or press **F2** on a focused card, row, door or title, to edit the name where it is. Enter or clicking away saves, Esc cancels, empty brings the default name back; the Rename… menu items and the dialog stay. Same checks and calls as the dialog (no new IPC). Checked on the simulator (`npm run check:rename-inline`, `check:ui-text`, `check:office`, `test:inlinename`), not on a real Mac or Windows.
