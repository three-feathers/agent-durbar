- **Team templates: the member editor, in the simulator only for now** (spec 111 T009, FR-002, FR-022, FR-023, FR-131, FR-132): *New template…* and *Edit…* open an editor with a template name and description and, for each of up to 8 members, a name, a role, a brief, the app (with its state in words), the model (*App default*, or "not offered here" for a saved one the app does not list), the reasoning effort the model offers, permissions and spending limit (the same rows as *New session*; the limit is in the app's unit and is cleared when the app changes), a custom agent id (checked when the member first starts), a character and *Send role brief*. *Add member*, *Remove* and *Move up/down* work from the keyboard; a mistake is said on its field; a save that main refuses keeps what you typed; Esc with unsaved changes asks "Discard changes?". A brief that came from a file shows *Brief from a file* and *Mark as mine*, which asks first. Names that read the same as another member's are marked. The section is not shown in the app until *Use…* and the create preview arrive (a later step).
