- **A helper started in the background no longer reads Done while it works** (spec 015 FR-018, issue #1141): when an agent launches a helper in the background (Claude Code's `run_in_background`, Copilot's background task), the agent's own call returns at once; the helper's chat block, card and transcript now stay Running until the helper itself finishes or fails, and a helper still running when its session stops reads Failed ("Stopped with its session"). Foreground helpers are unchanged. Checked with mapper tests and a simulator driver; not seen on a real session.
