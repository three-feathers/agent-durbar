- **Go to, a keyboard navigator** (spec 074, issue #548): Ctrl+J (⌘J on a Mac; changeable in Settings > Keyboard, with a clash check) opens the Ctrl+K box in a Go-to mode: floor, folder, agent, or C and a number for a chat; the chat opens with the cursor in the message box. Chats are numbered (C3 on desks, list rows and the chat header). Checked with unit tests and a simulator driver at 1440x900 and 1280x800.
