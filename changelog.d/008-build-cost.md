- **Build cost report** (spec 008 FR-181): `scripts/usage-receiver.js` is a tiny loopback receiver for Claude Code's OpenTelemetry metrics (node:http only; only per-day, per-model token and cost sums are written, never an email, id or session) and `npm run usage:day` prints a markdown table per machine and model, an API list-price estimate, not billing. Setup in `docs/build-cost.md`. Checked with `test:usage` (mutation-checked) and a loopback run on Linux; not run on macOS or Windows.
  `npm run usage:readme` also keeps the README's *Build cost so far* block, a badge and a spend-over-time chart (local SVG) current at every release.
  The pre-telemetry spend is no longer one day: `npm run usage:spread` spreads it over 2026-10-25 to 2026-11-06 (50% lines changed, 50% merged PRs per day; shown as faded, dashed bars in `docs/build-cost-days.svg`, estimated, total unchanged), and every machine publishes `docs/build-cost/data/usage-<machine>.json` (`"scope": "agent-durbar"`) at each release; the receiver now counts only Agent Durbar work (`OTEL_METRICS_INCLUDE_REPOSITORY=true`, `DURBAR_USAGE_REPOS`).
