- **Theme contrast now checks every colour form** (spec 070 FR-080, issue #1259): a theme that wrote a colour as `rgb()`, `hsl()`, a colour name or with transparency used to skip the readability check and repair, so low-contrast text could pass unnoticed. These colours are now measured (transparent ones over the page) and repaired like hex ones; a colour that cannot be measured, such as `currentColor`, is reported as unmeasured. Checked by unit tests only; no screen changed.
