- **Theme contrast now checks every colour form** (spec 070 FR-080, issue #1259): a theme that wrote a colour as `rgb()`, `hsl()`, a colour name or with transparency used to skip the readability check and repair, so low-contrast text could pass unnoticed. These colours are now measured (transparent ones over the page) and repaired like hex ones; a colour that cannot be measured, such as `currentColor`, is reported as unmeasured. A theme that sets a light drop-zone text colour without its own drop-zone background is now adjusted (and says so in Settings), and the Retro arcade world's drop zone is measured on its dark background. Colours written in a form Chromium does not accept (such as `rgb(50%, 199, 194)` or `rgb(185. 199. 194.)`) are reported as unmeasured instead of being measured as if valid. Checked by unit tests and the dark-fixture UI check.
