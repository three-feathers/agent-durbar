- **CI**: a GitHub outage of the Electron download no longer fails every job: a new workflow keeps `main`'s Electron download cache filled for Linux, Windows and macOS (it does nothing when the entry exists), `npm ci` waits out about 8 minutes of outage instead of 1, and electron-builder checks the Electron zip offline against the lockfile's checksums instead of fetching them from GitHub on every build (spec 008 FR-195).
