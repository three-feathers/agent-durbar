- **Instant tooltip on the top bar's status counts** (spec 001 FR-187, issue #875): hover a count (Working, Waiting, Idle, Error, Done) or Tab to it and the app's own tooltip appears at once, the same on Windows, macOS and Linux, naming the state and the count ("Idle · 7 agents idle or paused. Click to show only these.", "Click to show all." while that filter is on). Escape hides it; it stays below the count, inside the window, in every theme and in Serious mode, and is the count's accessible description. New shared helper `src/renderer/tooltip.js`; the other chips keep the system tooltip for now. Checked on the simulator only (`npm run test:tooltip`, `npm run check:ui -- --only check-status-tooltip`).
