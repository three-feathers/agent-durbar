- **Copilot SDK 1.0.32** (spec 058 FR-242..FR-244, spec 011 FR-096, issue #1667): the Copilot runtime moves from 1.0.24 to 1.0.32 for the coming sign-in app setting. Every Copilot session is started and resumed with a policy that keeps shell commands going through Durbar's own check (the new runtime would run "read-only" commands without asking; checked in Read-only on a real session), replayed history records are not shown or counted twice, and a limit request below the cap says *Close to the spending limit*. Tested with fakes, mutants and one real two-prompt check on Linux.
