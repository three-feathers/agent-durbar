- **A Claude session's instructions and settings no longer show in the process list** (spec 012 FR-179, issue #1379): the folder's `CLAUDE.md` text, a chosen agent profile and the folder's accepted hooks and rules went to Claude Code on its command line, which other accounts on the same computer can read (on Linux through `/proc`). They now go through private files (only your account can read them) that are removed when the session's Claude process ends. A Claude Code too old to read these files (before 2.1.69 for `CLAUDE.md`, before 2.1.281 for agent profiles) gets a message asking you to update it instead of the old command line. Checked with unit tests on a fake Claude process (macOS); not run with a real Claude session or on Windows.
