- **Smaller screenshots** (spec 050 FR-012, issue #759): the pictures in the README and on the website are now 256-colour palette PNGs, 63% smaller (the 76 linked pictures went from 15.6 MB to 5.7 MB, the site from about 15.0 to 5.6 MB). `npm run shots:docs` compresses every picture it writes, and `npm run shots:compress` does it by hand; a quality guard keeps the original when a picture would look worse. Plain Node, no new dependency. Checked with `npm run test:compressshots`, `test:site` and one simulator retake.
