# Cheeky Crew pictures: provenance (spec 077 FR-054)

One row per picture shipped in this folder. `npm run test:crew-assets` fails when a `.webp` here has no row, a row has no file, a picture is over its size cap, carries metadata (EXIF, XMP, ICC), or is not at the size the stage box needs (44x50 stage units at 4 pixels per unit, so 176x200).

Rules for every picture (owners, 2026-10-23): no real people, brands, game characters, logos, symbols, words, numbers or hand gestures; a person edits the final version and reviews it in the PR; the prompt is kept here verbatim (the pictures themselves carry no metadata); the README credits line comes with the real art.

**The pictures below are PLACEHOLDERS.** They are flat busts drawn by `scripts/crew-placeholders.py` (Pillow, no AI, no outside image) so the kit, the checks and the fallback can be built before the real art exists. The real pictures replace them under the same file names.
