# Real office world: Retro arcade (provenance, spec 097 FR-062..FR-069, spec 102 FR-250..FR-259, T206)

A hall of arcade cabinets, drawn **in code** (`scripts/build-arcade-pack.py`, from the owner-approved mockup's drawing, redrawn with level glass), no image-generation run (the helper kids are the exception, see below). One file pixel is one grid pixel, lossless WebP; two runs give the same bytes. Only the `.webp` files and `world.json` ship; this file stays in the repository. The Real office draws it behind the closed `WORLD_FLAGS.retro` until the flip (spec 102 T230).

- **Fictional:** no real brand, logo, franchise or character is drawn; the cabinets and fixtures are invented shapes.
