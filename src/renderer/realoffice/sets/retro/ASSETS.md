# Real office set: Retro pixel people (provenance, spec 097 FR-062..FR-069, spec 102 FR-205, FR-254, T201, T207)

Fifteen invented pixel-art people, each with 20 Real office frames: six seated busts (`typeA`, `typeB`, `waveA`, `waveB`, `think`, `rest`), seven standing seen from behind (`type`, `book`, `knock`, `letter`, `counter`, `runA`, `runB`), six standing facing us (`face-book`, `face-coffee`, `face-knock`, `face-letter`, `face-runA`, `face-runB`) and one seated asleep on a stool (`sit`, drawn separately: `scripts/build-arcade-sleep.py`). **One file pixel is one grid pixel**: the app draws it at an integer scale with `image-rendering: pixelated`. Only the `.webp` files and `set.json` (as `realoffice/sets/retro/set.js`) ship; this file stays in the repository.

- **Seated on a stool** (`sit`, the asleep pose, spec 102 FR-259, owner 2026-11-03): drawn by Codex image generation (`codex exec`, one run per person, reference = the person's own `face-book` frame at 8x, prompt in each person's `sit` line), then converted by `scripts/build-arcade-sleep.py` (magenta keyed out, cropped, shrunk to the grid with a block vote, head pixels snapped to the colours of the person's own standing head, the drawn skin tone replaced by the standing frame's skin tone so a face is never shaded to a dark blob, closed-eye lines kept, outline closed, lossless WebP; it refuses a frame whose mean skin colour is more than 25 off the standing frame's). Replaces the code-made frame of the same day. Each person's own standing frame was attached as the reference image of their run (a first batch of 2026-11-03 without it was thrown away). Made by Vikram's agent (Claude Code), 2026-11-03; waits for the owner's look.
- **Licence:** MIT, like the code and the crew art.
- **Which way they face (2026-11-14, spec 097 FR-191, #1743):** the standing frames are drawn facing **right** (the raised hand, card and cup are on the picture's right), so `set.json` says `"facing": "right"` and the lobby draws a visitor mirrored (the foot centre mirrors with it) to face its fixture. No file was changed.
- **What the art is (corrects the art cache's notes, which said "NOT generated by an AI image tool. Drawn by code" and also listed the pictures as `snapped` sheets):** every frame comes from a Codex image-generation sheet (`codex exec`, four sheets per person: `S` seated, `F` front, `A` and `B` from behind), then cut, **snapped to a pixel grid** (resized to a logical size, binary alpha, one 32-colour palette per person, exact 8x nearest-neighbour; the cache's `retro_snap.py` for r1..r8 and `new7/process7.py` for r9..r15). The code-drawn people (`retro-code`, `rig.py`) are an earlier, rejected fallback and are not used here.
- **Shrunk to the grid** by `scripts/build-arcade-pack.py`: each 8x frame becomes one pixel per block and is saved as lossless WebP (`VP8L`). A frame whose blocks are not uniform stops the build. Three frames of the cache were not on the 8x grid (`r4-waveA`, `r4-waveB`, `r8-waveA`, found 2026-11-01) and were shrunk by a block vote instead (no new colour), then looked at; the owner may ask for them to be redrawn.
- **Seated frames** of a person sit on one canvas (bottoms and the middle of their lowest rows together), so the engine can use one box for them (097 FR-013). `faceBox` (crown to chin, grid pixels, in `face-book`) is read from the width of the figure, row by row, and checked on a contact sheet.
- **Made by:** Vikram's agent (Claude Code), 2026-10-31 to 2026-11-01. **Approved by:** the owner (Vikram), 2026-11-01: the 8 first people earlier and the 7 new ones on 2026-11-01. They are no crew of Paco's (097 Q6), so the owner's approval is the record (102 Q11).
- **Fictional people (FR-067, spec 102 FR-209):** This person is fictional and must not resemble any real or famous person; no real person, celebrity, brand, logo or franchise is named.
