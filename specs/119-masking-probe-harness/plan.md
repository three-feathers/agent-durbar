# Implementation Plan: Masking probe harness (spec 119)

**Branch**: `119-masking-probe-harness` | **Date**: 2026-11-22 | **Spec**: [spec.md](spec.md)

## Summary

A seeded fuzz tool under `scripts/fuzz/`: a pure core (PRNG, piece generators by class, case composer, the five oracles, value-free output) and a runner (options, a reference copy of the masks taken from git at a fixed commit and compiled in process, the run loop with caps, private rows, the network guard). A toy masker with planted regressions proves the harness catches what it should. CI runs a small budget on PRs that touch the masks (a new `mask` output of the one CI decider) and names only failures new in the head; the large budget runs on owners' machines, never in a scheduled Actions workflow, reported through the private channel OP-1 picks. No new dependency, no network, no shell.

## Design decisions

- **D1 Layout.** `scripts/fuzz/core/` (pure: `prng.ts`, `pieces.ts`, `compose.ts`, `oracles.ts`, `emit.ts`, `vocab.ts`), `scripts/fuzz/surfaces.ts` (the registry, FR-006), `scripts/fuzz/runner/` (`probe-mask.ts` CLI, `ref.ts` reference copy, `private.ts` rows reader, `guard.ts` network guard), `scripts/fuzz/fixtures/toy-mask.ts` (FR-026). Tests: `scripts/test-probe-mask-core.ts`, `scripts/test-probe-mask-runner.ts`, `scripts/test-probe-mask-self.ts` (each under 30 s; the npm script `test:probe-mask` runs all three in `npm test`). The core imports nothing from Node but types; the runner passes `fs`, `child_process` and the clock in, so tests inject fakes.
- **D2 Piece generators are functions.** Each class of FR-004 is one generator `(rnd, vocab) => string` (or a wrapper `(rnd, inner) => string`). Unicode classes are computed once per run from the code point space (NFKC mapping and general category `Cf` via `\p{Cf}` in a `u` regex), not stored, and only when `process.versions.unicode` equals the core's `UNICODE_PIN` (else both classes are off and counted as skipped). Escape classes are encoder functions applied at random positions. The composer draws 1..6 pieces by weight, nests wrappers to depth 3, plants a value from the vocabulary at a known offset, and records the piece classes and offsets for the explain view (kept in memory only).
- **D3 Vocabulary export.** `_probeVocabularyForTest()` in `src/shared/redact.ts` returns `{ names, tokenClasses, limits, readings }` built from the same constants the rules use (no copy); a test asserts identity with those constants. The renderer masks get the same export only where they hold their own vocabulary. A run samples the union of the head's and the reference's vocabularies (a word the head drops is still planted); for an older reference without the export, the head's vocabulary is used for both.
- **D4 Reference copy.** `ref.ts`: resolve the commit (`git rev-parse --verify <ref>^{commit}`), list the closure by following relative `import`/`require` string literals from the registry's entry files (the same literal-following idea as `ci-changes.js`'s UI closure), `git show <commit>:<path>` each into `.probe-ref/<commit>/<path>`, check each file's blob hash with `git rev-parse <commit>:<path>`, transpile `.ts` with `typescript.transpileModule` (CommonJS), load with `require` from that folder. Reused across runs for the same commit (a stamp file of the hashes). Fails closed (exit 2) on any step.
- **D5 Oracles in the core.** `o1(headOut, refOut, planted)`, `o2(surfaceOut, readingOuts)`, `o3(streamHead, streamRef)` (per state, built on `o1`), `o4(out, overLimit)`, `o5(workSmall, workLarge)`; each returns `{ ok, pieces? }` where `pieces` are offsets for the explain view, never text. O0 wraps each surface call (`try` / class name).
- **D6 Output.** One `emit(line)` in `core/emit.ts` with the batch's planted values and private rows registered; a line holding a 6-character stretch of any is replaced by `[withheld]` and sets the failure flag. The runner writes only through it (stdout); stderr gets only `emit`-filtered setup errors. Seeds per FR-015 decided in the runner from the reference verdict.
- **D7 Private rows.** `private.ts`: resolve the path (option, env, default), `git rev-parse --show-toplevel` from its folder (not in a repo: allowed), `git check-ignore -q` and `git ls-files --error-unmatch` with argument arrays, size and row caps; each raw line registered with `emit` before `JSON.parse`, parse errors reported by line number only.
- **D8 Network guard.** `guard.ts` replaces `net.connect`, `net.createConnection`, `tls.connect`, `http.request`, `http.get`, `https.request`, `https.get`, `http2.connect`, `dns.lookup`, `dns.resolve*`, `dns.promises.*`, `dgram.createSocket` with throwing functions for the run; restored only at exit.
- **D9 CI decider.** `ci-changes.js` gets `mask`: the registry's closure computed the same way as D4 but from the working tree (literal-following from `scripts/fuzz/surfaces.ts`), plus `scripts/fuzz/**` and `scripts/test-probe-mask*`; unreadable = true. Because the base branch's copy of the decider runs on PRs, the output appears one PR after the decider change lands (as for every decider output; written in the spec's Changes when built).
- **D10 Seeds and verdicts in CI.** In CI mode the seed is `crypto.randomInt(2**32)`, held in memory only; `--seed` and `--replay` are refused. Each failing case is run against the reference with the same oracle: a reference pass makes it *new* (printed as oracle, surface, count; fails the step), a reference failure makes it *pre-existing* (dropped from the output entirely, does not fail the step). No secret, no scheduled workflow (OP-1). The `npm test` probe of the real masks keeps its committed seed but takes the same new-versus-pre-existing split against `HEAD^1`, and runs only when `GITHUB_EVENT_NAME` is `pull_request` (locally: when a merge-base with `origin/main` exists); every other event runs only the toy self-test.
- **D11 Output, asserts, crashes.** `emit(record)` takes typed records (kind enum, integers, names checked against the fixed sets) and is the only writer to stdout; a guard test scans `scripts/fuzz/**` for `console.`, `process.stdout`, `process.stderr`, `fs.write*`, `fs.createWriteStream` and child-process output outside `emit.ts` and `ref.ts`. `check(cond, code)` replaces value-printing asserts on case data (guard scan for `assert.strictEqual`, `deepStrictEqual`, `equal`, `match` and the like in those files). `process.on('uncaughtException' | 'unhandledRejection')` emits class name and phase code, exit 2. The guard scan covers `scripts/test-probe-mask*.ts` too (a fixed final `OK` literal allowed) and refuses literal-rebuilding forms (literal joins, regex literals outside the Unicode pattern file, numeric code-point arrays, `fromCharCode`/`fromCodePoint` on literals, character escapes in literals). Start refuses `--diagnostic-report*`, `--report-*`, `--heapsnapshot*`, `--heap-prof*`, `--cpu-prof*`, `--inspect*` in `NODE_OPTIONS` or `process.execArgv`.

## Testing plan (all offline)

| Test file | Covers | Planted mutants it must catch |
|---|---|---|
| `scripts/test-probe-mask-core.ts` | FR-003, FR-004, FR-012, FR-014, FR-020 source scan, oracles of FR-008..FR-011 on hand-built outputs | PRNG seeded from the clock; a generator returning a fixed list item; O1 comparing head with head; O2 passing a surface whose reading is dropped; O4 accepting a prefix; O5 on wall time; `emit` filter off; normalised (NFKC, case-folded) form not registered; a string literal the masks change, or a literal over 2 characters outside the fixed names, slipped into a generator, fixture or probe test file; a `console.log` outside `emit`; a value-printing assert on case data |
| `scripts/test-probe-mask-runner.ts` | FR-001, FR-007, FR-013, FR-015..FR-019, FR-021, FR-022 | reference loaded from the head; reference file hash not checked; a seed printed, or derived from the head sha, with `CI` set; a pre-existing case named or counted with `CI` set; the step failing on a pre-existing case; a crash handler printing message or stack; a diagnostic flag accepted; a private-row parse error quoting the line; private rows in the digest; the `npm test` real-mask probe failing on a shared case or running on a `main` push; Unicode classes on with a runtime Unicode version other than the pin; a probe test printing outside `emit`; a literal rebuilt by joining, a regex literal, a code-point array, `fromCharCode` or an escape left unrefused; `--show` on a non-terminal; a tracked or not-ignored private path read; a private row printed; network guard off; environment not cleared; a file left in the temp working folder after a run; an option value reaching git unvalidated |
| `scripts/test-probe-mask-self.ts` | FR-026, SC-001, SC-003 digest | the toy unmodified gives a failure (false positive); each toy regression not caught within the fixed seed and budget |
| `scripts/test-ci-changes.ts` (existing, extended) | FR-023 `mask` output | a registry-closure file gives `mask=false`; an unreadable diff gives `false`; a docs-only PR gives `true` |

Mutants are run on a fresh build each; a kill counts only when the intended assert's text fails (agent-notes: mutant false kill).

## Rollout

P0 spec (this PR) → P1 core + toy masker + vocabulary export, with tests (no CI wiring) → P2 runner, reference copy, private rows, guard, replay; `npm run probe:mask` usable by authors → P3 CI `mask` output and the PR lane step, budget measured; docs; the owners' large-budget runs after OP-1 (outside Actions). Each phase one PR, heavy profile, reviewed by Paco's side.

## Complexity tracking

None: no new dependency (the `typescript` package is already a dev dependency), no new process, no new workflow (a step in the existing required job), no new secret, no scheduled probe in Actions.
